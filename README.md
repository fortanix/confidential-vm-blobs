Blob dependencies for use with the Fortanix VME Rust compiler target. This package contains all required dependencies to allow executing the runner for the Fortanix VME Rust compiler target with the default settings. Concretely, it bundles a purpose-built kernel, OVMF firmware, init executable, and bootstub that are used by the Fortanix VME runner to launch compiled ELF binaries as confidential virtual machines.
